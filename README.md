# Nexus OS Core

Build the initial NEXUS AI OS frontend using the attached reference image as the primary visual direction.

This is a frontend/UI build only for now. Do not spend time building a real backend, database, authentication system, API integrations, or AI functionality. Those will be implemented later with Base44.

VISUAL DIRECTION

Recreate the overall feeling of the reference image:

sleek, premium, dark, cinematic, modern glassmorphism.

The glassmorphism is extremely important.

Use:

genuinely translucent glass surfaces

noticeable but controlled background blur

subtle borders/highlights around glass panels

layered depth

soft shadows

restrained blue/purple accent lighting

dark atmospheric background

generous spacing

rounded but sophisticated panels

Do not turn everything into glowing neon cards.

The design should feel like a premium operating system, not a gaming dashboard.

Keep the color palette restrained. The glass material, lighting and depth should create most of the visual richness.

NEXUS BRANDING

Use the provided Nexus logo as the actual brand mark.

Do not replace it with an AI-generated alternative.

The Nexus logo should appear consistently across:

sidebar/header branding

loading/initialization experience

app identity

relevant authentication/onboarding screens

mobile navigation

Keep the logo clean and sharp.

TYPOGRAPHY

Text quality is extremely important.

Use a premium, highly readable modern sans-serif.

Prioritize:

excellent typography hierarchy

clean spacing

accurate alignment

readable font sizes

strong headings

subtle secondary text

consistent capitalization

professional microcopy

Do not use awkward placeholder text, random text, excessive uppercase labels, or badly spaced typography.

The interface should look professionally designed even when functionality is only mocked.

CORE UI

Create the main Nexus dashboard inspired by the reference image.

Include:

left navigation

Nexus branding

dashboard/home

AI assistant

workspaces

projects/tasks

knowledge/files

calendar

communications

automations

analytics

settings

top search / command interface

main dashboard content

AI command area

glassmorphism cards/widgets

profile area

The exact layout can be intelligently adapted from the reference image rather than copied pixel-for-pixel.

FUNCTIONAL PLACEHOLDERS

Even without a backend, do not create dead UI.

Navigation items, buttons, cards and important controls should work on the frontend.

For example:

Clicking AI Assistant → open a realistic AI workspace placeholder.

Clicking Workspaces → open a workspace screen with realistic placeholder content.

Clicking Tasks → open a tasks interface.

Clicking Calendar → open a calendar placeholder.

Clicking Files/Knowledge → open a file/knowledge interface.

Clicking Automations → open an automation interface.

Clicking Analytics → open an analytics dashboard placeholder.

Clicking Settings → open the settings interface.

Buttons such as New Workspace, Create, Add, View All, etc. should trigger appropriate frontend interactions, modals, panels or placeholder pages.

These do NOT need real backend functionality yet.

The objective is that the entire UI feels alive and navigable, rather than being a static mockup.

SETTINGS

Include a proper Appearance section with:

Dark

Light

System

The dark theme should be the default and match the reference image.

The light theme should be independently designed rather than simply inverted.

Structure the UI using reusable theme tokens so the entire interface can switch themes consistently.

RESPONSIVE DESIGN

Build the interface responsively.

The desktop dashboard should closely follow the reference composition.

On mobile:

transform the sidebar into a mobile navigation system

reorganize dashboard cards vertically

preserve the AI command experience

maintain the glassmorphism aesthetic

make touch targets comfortable

avoid simply shrinking the desktop layout

ANIMATION

Use subtle, premium motion:

smooth page transitions

glass hover states

gentle card interactions

navigation transitions

modal transitions

subtle loading/initialization animation

Avoid excessive animations that make the product feel like a demo.

Everything should feel smooth and intentional.

IMPORTANT

Do NOT over-engineer the project.

Do NOT build backend functionality yet.

Do NOT add unnecessary features just to make the dashboard look busy.

Do NOT compromise typography or usability for visual effects.

Do NOT replace the Nexus logo.

Do NOT turn the UI into a neon/cyberpunk interface.

Use the attached image as the visual north star, while keeping the implementation clean, responsive, reusable and ready for a future Base44 backend.

The final result should feel like:

Nexus — a premium AI operating system, not another AI dashboard template.
